# Пары

Android-приложение для студентов ВолгГТУ: загружает расписание из Excel-файла учебного отдела и каждый вечер присылает уведомление с парами на завтра.

## Возможности

- Загрузка расписания из файла `.xls` или `.xlsx`: кнопкой в приложении или через «Открыть с помощью» / «Поделиться» из мессенджера, браузера или файлового менеджера.
- Автоматический поиск всех групп в файле и выбор своей.
- Ежедневное напоминание в выбранное время (по умолчанию 20:00): время пар, дисциплина, тип занятия, аудитория.
- Просмотр занятий на любой день.
- Светлая и тёмная тема.
- Работает без интернета, без рекламы и без сторонних библиотек.

Требуется Android 8.0 или новее.

## Установка

Готовый APK собирается автоматически при каждом изменении кода: вкладка **Actions** → последняя успешная сборка «Build APK» → раздел **Artifacts** → `Pary-apk`. Скачайте архив, распакуйте и установите `app-release.apk`, разрешив установку из неизвестных источников.

## Использование

1. Нажмите «Загрузить файл» и выберите файл расписания.
2. Выберите свою группу.
3. Разрешите уведомления и при желании измените время напоминания.
4. Кнопка «Проверить уведомление» сразу покажет, как будет выглядеть вечернее сообщение.

Когда выйдет новое расписание, просто загрузите новый файл — выбранная группа сохранится.

## Поддерживаемый формат

Приложение рассчитано на сетку расписания учебного отдела ВолгГТУ:

- группы расположены по столбцам (например, «ЭВМ - 2.3»);
- дни недели и академические часы («1-2», «3-4», …) — по строкам;
- у занятий указаны даты проведения («14.09.,12.10.,…»).

Если у занятия даты не указаны, используются все даты этого дня недели из левых столбцов таблицы. Ячейки, где лекция и лабораторная чередуются по неделям, разбираются раздельно. Если дата в файле не совпадает с днём недели, занятие пропускается, а после загрузки показывается замечание.

## Расписание звонков

| Пара | Время |
|------|-------|
| 1 | 8:30 – 10:00 |
| 2 | 10:10 – 11:40 |
| 3 | 11:50 – 13:20 |
| 4 | 13:40 – 15:10 |
| 5 | 15:20 – 16:50 |
| 6 | 17:00 – 18:30 |

Академические часы «1-2» соответствуют 1-й паре, «5-6» — 3-й и т.д. Время задаётся в `core/Lesson.java` (массив `TIMES`).

## Если уведомления не приходят

- На Android 12 и новее разрешите приложению «Будильники и напоминания» — в приложении есть подсказка с переходом в настройки.
- На Xiaomi, Huawei, Samsung и других оболочках разрешите автозапуск и отключите ограничения батареи для приложения.

## Сборка из исходников

Откройте проект в Android Studio и выполните Build → Build APK(s), либо соберите из командной строки:

```bash
gradle assembleRelease
```

Требуются JDK 17 и Android SDK (compileSdk 35). APK подписывается отладочным ключом, поэтому сборки с разных компьютеров нельзя установить поверх друг друга — перед обновлением удалите предыдущую версию.

## Структура проекта

```
app/src/main/java/com/zasaweryq/pary/
  core/XlsReader.java      — чтение .xls (OLE2 + BIFF8) без библиотек
  core/XlsxReader.java     — чтение .xlsx (zip + XML)
  core/ScheduleParser.java — разбор сетки: группы, дни, пары, даты, преподаватели, аудитории
  core/Schedule.java       — хранение и выборка занятий по группе и дню
  MainActivity.java        — главный экран
  Notifier.java            — уведомления и планирование напоминаний
  ReminderReceiver.java    — вечернее срабатывание
  BootReceiver.java        — восстановление напоминания после перезагрузки
```
