# Пары — расписание ВолгГТУ с напоминанием на завтра

Android-приложение (Android 8.0+):

- загружает файл расписания в формате учебного отдела (`.xls`, также `.xlsx`) — кнопкой или через «Открыть с помощью» / «Поделиться» прямо из Telegram или «Загрузок»;
- находит в файле все группы и даёт выбрать свою;
- каждый вечер в выбранное время (по умолчанию 20:00) присылает уведомление с парами на завтра: время, дисциплина, тип, аудитория;
- показывает занятия любого дня (стрелки ‹ ›, нажатие на дату — вернуться к «завтра»);
- работает без интернета и без сторонних библиотек.

## Как получить APK

### Вариант 1 — GitHub Actions (без установки Android Studio)

1. Создайте на GitHub новый репозиторий (например, `Pary`).
2. Загрузите в него всё содержимое этой папки (Add file → Upload files, перетащить папки целиком, включая `.github`).
3. Откройте вкладку **Actions** → сборка «Build APK» запустится сама (2–4 минуты).
4. В завершённой сборке внизу, в разделе **Artifacts**, скачайте `Pary-apk`, распакуйте и установите `app-release.apk` на телефон (разрешить установку из неизвестных источников).

### Вариант 2 — Android Studio

Откройте папку проекта (File → Open), дождитесь синхронизации Gradle, нажмите ▶ Run или Build → Build APK(s).

## Как пользоваться

1. «Загрузить файл» → выбрать `.xls` с расписанием.
2. Выбрать группу из списка.
3. Разрешить уведомления; при желании поменять время напоминания.
4. «Проверить уведомление» — сразу покажет, что придёт вечером.

Новое расписание — просто загрузите новый файл, выбранная группа сохранится.

## Что важно знать

- **Время пар** зашито по звонкам ВолгГТУ: 1 — 8:30, 2 — 10:10, 3 — 11:50, 4 — 13:40, 5 — 15:20, 6 — 17:00 (`core/Lesson.java`, массив `TIMES`). «Часы 1-2» в таблице = 1-я пара, «5-6» = 3-я и т.д.
- **Даты** берутся из самих ячеек («14.09.,12.10.,…»). Если у занятия дат нет — используются все даты этого дня недели из левых столбцов таблицы.
- Ячейки, где лекция и лаба чередуются (две половины ячейки с разными датами), разбираются раздельно.
- Если в файле дата не совпадает с днём недели, такое занятие пропускается и показывается замечание после загрузки.
- Чтобы уведомление приходило точно в срок на Android 12+, разрешите «Будильники и напоминания» (подсказка есть в приложении). На Xiaomi/Huawei/Samsung стоит также разрешить автозапуск и снять ограничения батареи, иначе система может «усыпить» напоминание.
- APK подписывается отладочным ключом сборщика. При сборке через GitHub ключ каждый раз новый — для обновления приложения удалите старую версию (расписание придётся загрузить заново).

## Устройство кода

```
app/src/main/java/com/zasaweryq/pary/
  core/XlsReader.java      — чтение .xls (OLE2 + BIFF8) без библиотек
  core/XlsxReader.java     — чтение .xlsx (zip + XML)
  core/ScheduleParser.java — разбор сетки: группы, дни, слоты, даты, преподаватели, аудитории
  core/Schedule.java       — хранение и выборка по группе/дню
  MainActivity.java        — экран
  Notifier.java            — уведомления и будильник
  ReminderReceiver.java    — вечернее срабатывание
  BootReceiver.java        — восстановление напоминания после перезагрузки
```
